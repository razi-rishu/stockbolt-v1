2. THE SAFE PERCENTAGE-VARIANCE RULE
--------------------------------------------------------------------------------
formatVariancePct(current, previous):
   previous 0 AND current 0     → "—"
   previous 0 AND current ≠ 0   → "New"
   otherwise                    → signed %, e.g. "+20.0%", "−20.0%", "0.0%"
                                  (computed over |previous| so a negative base
                                   reads intuitively)
The numeric field variance_pct is null when previous is 0 (stored by the merge);
the display string comes from formatVariancePct. Both are covered by tests.
