--------------------------------------------------------------------------------
2. HOW IT WORKS (reuse + no-regression)
--------------------------------------------------------------------------------
  • The CURRENT-period query keeps the SAME queryKey the report already used
    (['pl'|'balance_sheet'|'trial_balance', company_id, …]) so, off-compare, the
    key + fetch are byte-for-byte unchanged. Off-compare, curFrom/curTo == the
    picker range, the export rows == the old export rows, and the subtitle ==
    the old subtitle → the single-period view is functionally identical.
  • Turning Compare on fires ONE extra query (the previous period) via the same
    adapter method, then merges client-side (AC-2A). Fiscal-aware Year comparison
    re-anchors the current window (only in compare mode).
  • Variance coloring: neutral account rows; bottom-line totals (Gross/Net
    Profit, Total Assets/Liabilities/Equity, TB Difference) colored green/red
    with ▲/▼. Variance % uses the AC-2A rule (— / New / signed %).
  • Print = existing window.print() (+ data-print-hide chrome). Excel = existing
    ReportActions/downloadXLSX with comparative columns. "PDF" = browser
    Print → Save as PDF (no new engine), per the approved spec.
