3. ADAPTER PARITY DESIGN (why the preview numbers are trustworthy)
--------------------------------------------------------------------------------
previewYearEndClose:
  - Computes the fiscal window from companies.fiscal_year_start (month/day):
        fy_start = make_date(fiscal_year, m, d)
        fy_end   = fy_start + 1 year - 1 day
  - Aggregates income+expense GL in [fy_start, fy_end], EXCLUDING prior
    year_end_close legs — the SAME filter the P&L report (AC-1.0) and the close
    RPC use. Therefore:
        net_income (preview) == P&L net profit == what close_fiscal_year() posts.
  - Builds the exact closing legs by account:
        income  leg: Dr = max(sum_cr - sum_dr, 0), Cr = max(sum_dr - sum_cr, 0)
        expense leg: same formula (zeroes any balance, incl. contra/archived)
        RE leg:  profit -> Cr 3100 = net_income ; loss -> Dr 3100 = |net_income|
                 zero  -> no RE leg
    -> total_debit == total_credit (balanced badge in the UI).
  - Read-only. Posts nothing.

getNextCloseableFiscalYear:
  - earliest GL date -> earliest fiscal year with activity.
  - walk forward; first ended (fy_end <= today), un-closed year is the answer.
    (priors are already closed because closed years are skipped in order ->
     mirrors the RPC's sequential guard). null = nothing to close / all caught up.

closeFiscalYear / reopenFiscalYear:
  - thin wrappers over RPC close_fiscal_year(p_fiscal_year) /
    reopen_fiscal_year(p_fiscal_year)  (phase56).

listFiscalYearCloses:
  - selects fiscal_year_closes newest-year-first; returns [] if the table is
    not applied yet (graceful).

4. UI DESCRIPTION (screens + states)
--------------------------------------------------------------------------------
PREVIEW (Region A):
  - Amber banner "PREVIEW — NOT POSTED" + subtext "This is a draft calculation.
    No journal entry has been created yet." (visible on screen AND in print).
  - Year header: "Fiscal Year 2024 · 1 Jan 2024 – 31 Dec 2024 · ready to close".
  - Actions (hidden in print): [Print / Save PDF] (secondary),
    [Close fiscal year] (primary; hidden without accounting.write; disabled if
    Retained Earnings 3100 is missing).
  - Net-income tiles (3): Total Income · Total Expenses · Net Profit/(Loss)
    (green profit / red loss), with a "View full Profit & Loss ->" parity link.
  - CLOSING IMPACT SUMMARY (key/value): Fiscal Year · Income accounts to be
    zeroed · Expense accounts to be zeroed · Journal lines in the closing entry
    · Net Profit/(Loss) · Retained Earnings account · Period lock date after
    close · Current lock date.
  - Plain-language explanation callout (profit / loss / break-even / no-activity
    variants).
  - CLOSING JOURNAL ENTRY (preview) table: per-account Dr/Cr legs, the RE row
    emphasized, totals row, and a "Debits = Credits" balanced badge.

PRINT / SAVE PDF:
  - window.print(). App chrome + Region B + on-screen action buttons carry
    data-print-hide. The amber "NOT POSTED" banner prints. A data-print-only
    header adds Company · "Year-End Close — Preview (Not Posted)" · FY range.
  - "Not posted" is therefore guaranteed in the output two independent ways.

CONFIRM -> SUCCESS (Close):
  - Modal "Close Fiscal Year 2024?" restates net income + RE (3100) + lock date;
    explicit [Cancel] / [Close fiscal year]; spinner + non-dismissable while
    pending. On success the SAME modal swaps to a check + "Fiscal year 2024
    closed" + entry number as a <DocLink> to the JE + [Done].

CLOSED YEARS (Region B):
  - Columns: Fiscal Year · Period · Net Income · Status badge (Closed/Reopened)
    · Closed on · Entry (JE DocLink) · [Reopen].
  - Reopen appears ONLY on the latest closed year (LIFO) and only with write
    perm; its own confirm -> success modal.

STATES:
  - Loading: preview skeleton + list spinner + button spinners.
  - Empty: "All caught up" (some closed) vs "Nothing to close yet" (none);
    "No fiscal years have been closed yet."
  - Validation notices: RE-missing (blocks close), no-activity (informational).
  - Errors: friendly mapping — permission (42501), engine-not-installed
    (function missing / schema cache), else the raw guard message.
  - Mobile: tables in overflow-x-auto; EN + AR (RTL inherited).

NOTE: no BackButton — consistent with its sibling Accounting nav pages
(Period Lock, General Ledger) which are top-level nav destinations, not leaves.
